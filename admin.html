How to get your token (one time, 2 minutes)
  1. Open github.com/settings/personal-access-tokens/new while signed in to GitHub.
  2. Give it a name like “Melao’s website” and an expiry you are comfortable with.
  3. Under Repository access choose Only select repositories and pick melaos-real-estate.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else alone.
  5. Generate it, copy it, and paste it above. GitHub only shows it once.

Keep it to yourself. That token can change the website. Do not share it or paste it anywhere else — each brother should make his own, so the history shows who changed what. If one leaks, delete it on GitHub and make a new one.
